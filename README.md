# 医途 · 医学生学习助手

专为医学生设计的学习管理工具（网页版 v2.0 树洞版）。

## 🚀 在线使用

**👉 https://conquer2626882.github.io/website/**

手机、电脑浏览器打开即用，无需下载安装。

## ✨ 功能

| 模块 | 说明 |
|---|---|
| 规划 | 长期规划（考研院校等）+ 短期目标（期末/考研分数），含量化指标与倒计时 |
| 日计划 | 任务 + 科目 + 开始时间，勾选完成/未完成，每日自动存档，可写日总结 |
| 计划执行 | 点「▶ 开始」进入全屏专注页，正计时计时器，实际用时自动记录 |
| 学科计划 | 如「英语六级」专属任务清单，四色反馈（已完成/今天到期/已逾期/未开始）+ 进度条 |
| 智能月总结 | 规则引擎基于当月数据自动生成「优点 / 问题 / 建议」学习月报 |
| 待办 | 记事本式清单：过期/今天/以后/已完成四组，支持优先级 |
| 复习记忆 | 艾宾浩斯遗忘曲线，学习后 1/2/4/7/15/30 天共 6 轮提醒，逾期标红 |
| 习惯打卡 | 自定义习惯，早起类可记录起床时间，连续天数 + 月历视图 |
| 树洞 | 每日激励语（6 种心情）、X 年之约（到期自动弹窗问「实现了吗」）、时光机信件（到期解锁） |
| 导出中心 | 努力明细表 / 量化统计表 / 全量备份（XLSX）+ PDF 学习报告 |

## 📱 数据说明

数据保存在**打开网页的那台设备**的浏览器本地（localStorage），不上传任何服务器，隐私安全。

- 换设备或清缓存前，请用右上角 **⚙️ → 导出数据（JSON）** 备份，之后可导入恢复
- 也可定期导出「全量数据备份.xlsx」作为人可读的表格存档

## 📲 手机添加到主屏幕

- iPhone Safari：分享 → 添加到主屏幕
- Android 浏览器：菜单 → 添加到桌面

即可像 App 一样使用。
